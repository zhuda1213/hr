# 红星招聘 · 前台 H5 + 管理后台原型

红星实业集团招聘平台的静态高保真原型，纯单文件 HTML，无构建、无外部依赖，打开即用。

## 页面

| 路径 | 说明 |
| --- | --- |
| `/`（`index.html`） | 候选人移动端 H5：首页、职位、职位详情、投递、我的简历、投递记录、登录注册、模拟扫码 |
| `/admin/` | HR 管理后台：数据看板、岗位管理、候选人管理、人才库、黑名单、账号与角色权限、系统设置 |

## 说明

- 数据仅存在浏览器 `localStorage`（H5 使用 key `hx_h5_v1`），刷新保留、换设备/换浏览器不共享，属于纯前端原型，不对接后端。
- 「我的 → 重置演示数据」可把 H5 恢复为初始种子数据。
- 后台建议用桌面浏览器访问（≥1280px），H5 建议用手机或 DevTools 移动视图（390px）查看。

## 部署到 GitHub Pages

1. 仓库 Settings → Pages → Source 选择 `Deploy from a branch`，分支 `main`，目录 `/ (root)`。
2. 保存后约 1 分钟可访问 `https://<用户名>.github.io/<仓库名>/`，后台在 `.../admin/`。
3. 仓库根目录已放置 `.nojekyll`，避免 Jekyll 处理静态文件。
